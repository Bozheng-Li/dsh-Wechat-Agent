# 全局身份、按需记忆与统一目录 · 未发布

2026-11-06，Windows x64，DeepSeek Harness `0.2.1-rc.5`。承接会话人设、统一工作目录和定时 @ 的已有源码更新，补齐消息与记忆边界并完成整合验收。基础版本仍为 `0.2.0-preview.2`；本次是源码及本地构建，没有发布新的 npm 版本或替换正在运行的插件。

## 已接入的使用流程

- 全局工作目录只设置一次，工作空间、会话记录、局部及长期记忆、素材、任务、登录资料和缓存均从该目录生成。迁移校验完整数据和新实例，保留原目录；复制或新实例验证失败时回到原位置。重启读取已保存的位置。
- 全局身份位于工作目录根部的 `AGENT.md`。每轮 Agent 执行读取正文，再叠加当前会话的人设、账号要求及该会话可用的记忆。页面草稿不被轮询覆盖，外部编辑后的过期版本不能覆盖新文件。
- 每个群和私聊均可独立选择内置或自定义人设，也可跟随默认人设；名字与唤醒词同时用于昵称触发和回复。普通聊天和到期 Agent 任务使用同一份会话人设。
- 长期记忆可选择每轮附带或由 Agent 按需查询。近期窗口保持连续对话；查询工具只读当前会话资料，没有任意文件访问或跨会话参数。
- 群聊提醒按当前群成员名字选择一人或多人，“提醒我”使用发起人的真实微信标识。发送前重新核对成员和账号，实际微信消息携带原生 @ 字段；回执不明时不重发。

## 本轮修复与触发条件

| 触发条件 | 原行为 | 修复及验证 |
| --- | --- | --- |
| 第一问生成期间，同群又收到消息，模型随后查询会话记忆 | 查询读取最新文件，将后来才到的内容混入第一问 | 查询使用与本轮提示词相同的接收范围；后续问题仍能读取后到消息及前一个已确认回复 |
| 为本轮上下文压缩时省略了某个细节，Agent 按关键词查询 | 查询只能读取压缩后的文件，找不到本轮原文细节 | 保留压缩前的本轮快照供只读查询，输出长度仍受限制 |
| 旧查询在记忆清空后继续执行 | 旧快照可能继续提供清空前的资料 | 查询核对记忆代次，清空后拒绝读取旧资料 |
| 长期记忆 Markdown 损坏 | 读取失败被表现为没有匹配内容 | 查询明确返回读取失败，保留损坏文件供修复 |
| 保存空白或过期的全局身份草稿 | 先取消正在执行和排队的回复，再报校验错误 | 停止任务前先校验正文及版本；无效或过期请求不影响回复，内容未变时不取消任务；真正写入前仍核对文件版本 |
| `AGENT.md` 含损坏的 UTF-8 字节 | 静默替换为乱码后进入提示词 | 严格解码并报可理解的错误，接受正常 UTF-8 与 BOM，原字节保留供修复 |

新增七项回归用例；其中后到消息混入、损坏字节、无效草稿取消和过期草稿取消四项先在原实现中复现失败，修复后全部通过。
