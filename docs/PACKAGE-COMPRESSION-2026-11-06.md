# 安装包体积与无损压缩 · 2026-11-06

`0.2.0-preview.6` 的完整公开 npm 安装包为 **191.73 MB（182.84 MiB）**。本轮仅重新编码原包的压缩层，生成 npm 兼容的 **183.06 MB** `.tgz` 和用于手动解压的 **129.78 MB** `.tar.xz`，全部运行文件、表情原图、说明与许可证保持原始字节。

候选包保存在本机 `release/unreleased-compression-20261106/`，属于未发布产物。当前 npm 公开下载仍使用已经发布的原包；版本号与正式版本记录保持原值。

## 体积来源

完整安装文件中的 Python 与依赖为 205,493,296 字节，微信组件为 228,145,071 字节，合计约 **99.40%**。最大单文件是 Frida 的 `_frida.pyd`（157.91 MB）和 `WeChatWin.dll`（101.36 MB）。插件的三个 JavaScript 运行入口合计 1.16 MB，30 张内置表情及其清单、许可合计 1.29 MB。

本机 npm 的原始打包参数已经使用 gzip `level: 9`。本轮使用 7-Zip 21.07 的不同 Deflate 实现进一步压缩 `.tgz`；XZ 使用 LZMA2、BCJ 过滤和 64 MiB 字典取得更大幅度的压缩。过滤与压缩都能精确还原输入字节。

## 分发选择

保持现有 DSH / npm 安装方式时使用 `.tgz`，本轮实测可减少约 4.52% 下载量。`.tar.xz` 适合提供单独的离线下载，用支持 XZ 的工具先解压；npm 和当前 DSH 的 npm 下载链不会直接安装这个格式，也不会因本机试压自动改为 XZ。

本轮候选包由原公开包还原出的 tar 流生成，保存了原公开包中的更新日志。本文和源码更新日志记录的是本次未发布的试压结果。后续正式 npm 发布需要使用新的版本号及其对应更新日志，继续遵循[开发与发布流程](DEVELOPMENT.md)。
