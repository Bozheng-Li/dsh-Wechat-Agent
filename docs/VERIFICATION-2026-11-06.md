# 0.2.0 插件优化验证

2026-11-06，Windows x64，DeepSeek Harness `0.2.1-rc.5`。插件版本 `0.2.0-preview.1` 为源码及本地预览更新，未发布 npm、插件市场或 GitHub Release。

## 完成的功能

- 会话授权按名称、备注和 ID 搜索；模型、人设、存储各有独立设置页。
- 显式设置人格提示词、昵称别名、背景、表达风格、模型参数及工作空间。
- 按账号和私聊／群聊分别保存记录，支持全局或单会话目录；迁移保留旧文件并检查冲突。
- 每群单独选择默认回复、昵称唤醒或随机 5–20 条消息后主动参与。原有授权群继续使用默认模式，新模式需要在对应群的设置中开启。
- 当前会话显示运行与等待任务，可以单独取消；全局取消仍有明确的独立按钮。
- 展开或翻页查看记录时固定浏览位置，回执状态仍会更新；新增记录显示提醒，刷新返回最新一页。长路径点击展开。

## 本轮发现与修复

| 触发条件 | 修复 | 验证 |
| --- | --- | --- |
| 回复期间新增或撤销另一个会话授权 | 新增授权不取消任务；撤销只取消目标会话，不重置其他群的参与计数 | 先复现旧行为，再验证运行中回复、排队任务及计数保留 |
| 修改当前账号的补充回复要求 | 只重置该账号的会话引用，保留其他账号上下文 | 保存和重新读取后均验证隔离 |
| 单会话取消请求缺少会话标识 | 明确拒绝不完整请求，不退化成全局取消 | RPC 边界回归及实际页面点击 |
| 查看旧记录期间收到新消息 | 以记录标识固定分页位置；失效位置明确提示刷新 | 新记录到来前后页面无重复、漏项或串会话；回执更新仍可见 |
| 窄窗口显示较长记录路径 | 保存位置默认折叠，操作区换行 | 430×900 和 1280×940、明暗主题检查 |
