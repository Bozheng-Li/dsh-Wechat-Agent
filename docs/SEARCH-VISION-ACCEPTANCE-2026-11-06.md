# 公开搜索与图像理解实测 · 2026-11-06

本轮使用运行中的 DSH 模型与凭据服务，发送公开论文查询及两张人工生成的测试图；没有发送微信消息、修改账号设置或导出凭据。测试后当前账号、配置指纹和微信在线状态保持一致，临时验收插件已移除。

## 联网搜索

- 默认公益 Tavily 的直接查询返回 arXiv 原文；当前聊天模型实际调用 `wechat_web_search`，在上一轮“上不了网”的上下文中重新查询，返回《Membership Inference Attacks From First Principles》、六位作者及 `https://arxiv.org/abs/2112.03570`。作者列表可与本轮 PDF 摘要和作者主页结果交叉核对。
- DeepSeek 原生搜索直接查询成功返回 arXiv 来源，证明独立凭据和原生接口可用。模型查询得到的部分结果缺少摘要且与目标论文相关性不足，因此模型明确表示本轮未核对成功；不能将此项写成“完整作者回答通过”，也不能把搜索结果质量不足说成连接失败。
- 一次较低输出预算的 DeepSeek 搜索回答未完成，未被当成有效回复；使用正常 4096 token 预算的复验完成并给出上述限制。本轮没有更改用户保存的输出预算或自动切换搜索服务。

## 图像理解

使用两张 1600 × 1000 PNG：第一张是数字 `7316`、左侧红圆与右侧蓝色方形；第二张是数字 `8429` 与绿色三角形。

- 单图实际识别出数字、颜色、形状和位置关系。
- 双图实际返回严格 JSON 字符串数组，数字和图像内容没有交换。
- 为验收设置的强制签名没有污染内部视觉笔记或 JSON。
- 这里验证清晰图像的文字与主体识别，不将模型对用途、精确几何比例的推测视为确认事实，也不将附件接入等同于微信图片已投递。

首轮图像夹具误传了 Buffer，DSH 按实际 base64 输入契约拒绝；改正测试夹具后两项实测通过，产品代码无需改动。
