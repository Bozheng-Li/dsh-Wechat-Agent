# 提示词系统

[返回总架构](01-总架构.md)

## 资源与加载

`prompts/loader.mjs` 是提示词文件统一入口：`readPrompt(name)` 读取 Markdown，`promptText(name,key,values)` 读取 JSON 中的字符串并插值。路径仅允许包内 `prompts/` 的受限相对名，UTF-8 文件长度受控，按文件签名缓存；读取、字段或插值失败会明确报错，不用空文本代替。安装包只复制 `package.json.files` 中逐项列出的 Markdown/JSON 资源，新增模板必须同步清单。

## 分组与组合

| 目录 | 内容 |
| --- | --- |
| `identity/`、`personas/` | 默认全局身份、唯一默认助手的预设与前端可用人设数据 |
| `reply/`、`format/`、`agent/` | 回复规则、语言边界、提示块组成、能力与事实搜索要求 |
| `conversation/`、`memory/`、`vision/` | 自然陪聊判断、摘要/提取/查询、真实图片理解 |
| `work/`、`tasks/`、`remote/` | 原生工作和任务结果提示、提醒、只读查询意图 |
| `moments/` | 朋友圈评论/点赞/发布、素材隐私、图片依据、好友回复 |
| `digests/`、`recovery/`、`diagnostics/` | 简报、恢复与状态诊断文案 |

`prompts/reply/compose.mjs` 将群/私聊角色、语言边界、全局身份、当前人设、管理员备注和当前工具说明合成模型系统提示；`progressive.mjs`、`progressive-dialogue.mjs` 支持分步展示能力。聊天模型的工具列表由真实权限决定，提示词不能授予服务端未开放的能力。自然陪聊/视觉/意图等内部模式使用独立输出契约和空工具列表。

## 自定义内容与安全

包内默认提示与用户工作目录 `prompts/` 下的自定义身份/人设不同：前者由 `resourcePath` 从安装包读，后者经 `ConfigurationRepository` 校验 YAML 引用的 Markdown 内容。用户外部编辑后需要重新启用插件生效（全局身份存在下一轮重读例外）；保存冲突应保留草稿。引用聊天历史、朋友圈或网页文字都只作为数据，不可当成更高优先级的配置指令。

## 修改与验证

更新提示时同步验证输出格式、工具边界和资源打包：`tests/prompt-composition.test.mjs`、`tests/public-language.test.mjs`、`tests/progressive-prompt.test.mjs`、`tests/package-resources.test.mjs`；视觉与自然规则另有 `tests/vision-routing.test.mjs`、`tests/natural-chat.test.mjs`。
