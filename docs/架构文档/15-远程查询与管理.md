# 远程查询与管理

[返回总架构](01-总架构.md)

## 权限模型

`modules/remote/authorization/` 管理全局和会话管理员名单。只有真实微信身份、已授权会话、开关 `remoteEnabled` 与允许的管理员 ID 同时满足时，才能从微信发起只读远程查询。DSH 本地页面的 Owner 身份负责维护管理员名单，但**不能**以一个管理员的微信文字绕过会话权限。

## 输入路径与可执行范围

`commands/index.mjs` 处理明确命令，`intent/index.mjs` 识别自然表达；`RemoteService.query` 可在 `remote-intent` 模式调用一次无工具模型，严格解析成有限的 `computer`、`tasks` 或 `task` 请求。模型只判断意图，不执行命令。`computer/status.mjs` 从本机读取 CPU、内存、磁盘和宿主进程状态；`tasks/status.mjs` 读取 DSH Agent 任务快照，`tasks/format.mjs` 以固定文案格式化结果。管理者不能通过此接口执行任意脚本或修改现有 DSH Agent。

`RemoteService.assertAllowed` 在意图判断前、判断后、每项状态读取后以及消息发送前复核账号、会话、管理员和在线状态。查询记录不混入普通聊天历史和记忆，避免群里其他成员通过 `wechat_memory` 读到宿主信息。工作会话可在具备管理员权限时调用状态工具，但仍须通过同样的服务端复核。

## 维护与验证

添加新的远程能力必须明确规定只读数据源、最小可见字段和有限意图枚举，并更新 `authorization/policy.mjs` 与测试。回归入口：`tests/remote-administrators.test.mjs`、`tests/remote-task-status.test.mjs`、`npm run test:remote-native`、`scripts/test-authorization-ui.cjs`。
