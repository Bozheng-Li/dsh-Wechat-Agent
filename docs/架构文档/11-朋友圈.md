## 两级实现

`backend/wechat/protocol/moments*.ts` 负责实际微信协议请求：时间线、好友主页、评论与图片读取、标签/联系人可见范围以及发布、删除、点赞、评论等写入；`modules/moments/service.mjs` 是聊天/工作可调用的业务授权入口，解析 `speaker`（当前发起人）、`account`（扫码账号）、`contact`（准确联系人）主体，复核账号、会话及管理员权限，写入前固定请求编号。管理页面的 Owner RPC 由 `backend/app/service.mjs` 分发，Owner 授权与微信聊天管理员身份不能混为一谈。

## 功能群与独立状态

| 领域 | 关键文件 | 状态与规则 |
| --- | --- | --- |
| 读取/本人定时回复 | `service.mjs`、`automation.mjs`、`friend-replies.mjs` | 读取真实动态与评论，按账号/动态/评论防重；好友接话须明确指向父评论 |
| 好友点赞 | `likes.mjs`、`like-requests.mjs` | 手动或定时轮次、联系人和动态锁定，未知回执不补发 |
| 分轮互动 | `interactions.mjs`、`interaction-read.mjs`、`interaction-content.mjs`、`interaction-schedule.mjs` | 预览/编辑/生成/执行，同目标及轮次校验 revision，自动和手动互斥 |
| 发布计划 | `publishing.mjs`、`publishing-content.mjs`、`publishing-review.mjs`、`arrangement.mjs` | 保存计划，分时段产草稿，检查来源与可见范围后提交 |
| 素材库 | `material-store.mjs`、`materials.mjs`、`material-privacy.mjs` | 本账号隔离随手记/图片/聊天启发；聊天取材先遮蔽身份并审查公开性 |
| 图片依据 | `image-context.mjs`、`image-stream.mjs`、`media.mjs` | 真实图片字节经校验后读图，不凭数量、URL 或旧描述臆测 |

## 写操作的一致性

业务层会固定 `requestId`/`clientId`，持久记录待发送意图，提交前复核动态作者、内容哈希、会话授权与当前账号；收到服务端确认才标记成功。多轮点赞、评论和自动回复对 `unknown` 停止自动后续操作，启动后保留未知状态并要求核对。删除历史展示记录不代表撤回微信动态，也不能删除防重复所需凭据。自动化默认关闭，修改配置只安排未来轮次，不补跑错过的轮次。

## 前端与验证

UI 在 `frontend/pages/moments/`：本人/好友动态、发布与计划、互动、素材、定时接话。共享校验见 `shared/moments*.mjs`。测试选择 `tests/moments-protocol.test.mjs`、`tests/moments-publishing.test.mjs`、`tests/moments-materials.test.mjs`、`tests/moments-interactions.test.mjs`、`tests/moments-friend-replies.test.mjs`、`tests/moments-likes.test.mjs`、`tests/moments-publication-recovery.test.mjs`。
