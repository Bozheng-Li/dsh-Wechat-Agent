# 素材库与表情

[返回总架构](01-总架构.md)

## 模块边界

`modules/media/library.mjs` 的 `MediaLibrary` 管理聊天回复所用的内置表情、自定义图片与表情包；此库与朋友圈的 `modules/moments/materials.mjs` **完全分离**，后者有独立授权、图片目录和公开性检查。前端工作区在 `frontend/pages/media/`，Owner RPC 在 `modules/media/actions.mjs` 接入。

## 资产生命周期

1. `builtin-stickers.mjs` 从包内 `assets/stickers/` 提供内置素材，构建时验证原始字节、尺寸和版权声明。
2. Owner 可导入 ZIP 或单张图片；`zip.mjs` 检查条目，`validation.mjs`/`limits.mjs` 约束账号、文件名、大小和数量，`image-format.mjs` 校验图片真实编码及尺寸。库中记录启用状态、分组、名称和描述。
3. 会话回复时按账号配置的启用开关、概率与最小消息间隔决定是否提供 `wechat_reply_media`；用户明确要图时走主动工具路径。模型只能从当前可用资产中选择，发送前再次解析资产并准备内容。
4. `prepareSendContent` 将静态 PNG/JPEG 按协议发送；GIF/WebP 需要通过运行资源转换为可发送的首帧，原文件仍保留。表情 `face` 不调用图像理解；普通图片经过真实字节校验后才能描述。

## 配置与一致性

`config.yaml` 中 `mediaDefaults` / `media` 控制分组、素材启用和概率；素材元数据和文件由库本身维护。外部删除素材或内容校验失败时停止发送该资产，不能退回凭文件名猜内容。多素材回复发送时沿用会话层 `sending` → 服务端回执状态机，部分成功不重发未知片段。
