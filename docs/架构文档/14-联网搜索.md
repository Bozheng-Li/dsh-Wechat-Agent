# 联网搜索

[返回总架构](01-总架构.md)

## 服务组成

`modules/search/service.mjs` 实现 `SearchService`：根据当前 `modelConfig.searchProvider` 选择 Tavily 或 DSH/DeepSeek 搜索，限制查询响应大小、来源 URL、摘要与图片数量。`fallback.mjs` 负责首选服务失败时的一次受控回退；`errors.mjs` 分类外部接口与验证错误。模型执行器的 `searchTool` 把服务注册为 `wechat_web_search`，工具执行结果附带来源链接，最近一次搜索状态供工作台查看。

## 触发与边界

仅当 `modelConfig.webSearch` 开启且当前模型模式允许工具时才向模型提供搜索能力。复杂、时效性或可核对事实需要搜索时由模型按工具说明调用，普通聊天不会直接由消息入口向公网提交全文。工作原生会话若启用插件搜索，会限制宿主同名搜索入口，避免绕过本轮指定服务的凭据与回退策略。

凭据通过 DSH Credentials 服务保存，配置里只保留服务选择和 Tavily HTTPS Base URL；`SEARCH_CREDENTIALS` 中给出了两个逻辑键名，不能把密钥写进仓库、文档或 `config.yaml`。响应仅接受 HTTP(S) URL，拒绝带凭据 URL 和超过上限的内容；搜索失败不伪造可核对来源。

## 修改与验证

新增服务提供方应扩展配置校验、凭据登记、返回结构归一化和错误分级，保持“最多一次回退”语义。测试：`tests/web-search.test.mjs`、`tests/search-fallback.test.mjs`、`tests/factual-search-policy.test.mjs`，原生隔离验证入口 `scripts/test-search-native.cjs`。
