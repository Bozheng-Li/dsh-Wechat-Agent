# 图片按需理解 · 2026-11-07

本次为本地未发布修复。保留图片记忆和微信授权，不发送真实微信测试消息或群通知。

## 触发条件与修复

- 原先收图后的后台记忆维护、回复前处理会自动理解所有未分析附件；现改为只保存文件和缩略图。没有看图需求时，不发起视觉请求，也不把“尚未查看”误记为模型理解失败。
- 私聊只发图、群内只有 @ 加图时，原先程序自动补上“请理解图片或表情包”。现使用中性的收图说明，当前没有文字问题时不主动分析；上下文确实需要看图时才由模型按需调用。
- 当前及近期普通图片通过 `wechat_read_image` 选择相关图片，问题、消息归属和原始图片顺序明确传入。只查看被选中的图片；本轮重复核对相同图片与相同问题复用已取得的结果。已有描述足够回答时不重新调用视觉接口。
- 原生表情包从当前图片列表、历史图片检索和视觉失败重试中排除；直接请求表情包的视觉接口也会拒绝。素材库的批量理解跳过已归类的表情包，并显示真实跳过数量。表情包文件、已有名称、含义和发送功能保留。
- 按需理解继续保存到原会话和独立图片记忆。保留账号与群隔离、接收时刻边界、到期与删除检查、取消保护、图像清晰度说明，以及子调用继承父回合模型配置的规则。
- 实际模型服务当前返回 `ACCOUNT_QUOTA / Insufficient Balance`。已将该类错误显示为模型账号余额或额度不足；不能把微信在线或模拟接口通过当成真实视觉模型可用。
