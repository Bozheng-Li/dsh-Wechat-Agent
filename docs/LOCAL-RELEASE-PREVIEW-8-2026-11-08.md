# 0.2.0-preview.8 发布与升级记录

本版按用户要求，将已经本地验证的插件更新发布到 GitHub 与 npm，并重载本机插件。范围包含人设输入与原生会话上下文修复、显式推理强度、记忆检索及后台维护、工作台界面和知识库移除。保留原账号、授权、自动回复、记忆及历史，维护群通知保持关闭。

当前阶段：完整自动化与安装包审计已通过，正在完成公开发布与本机升级。尚未将版本准备、上传请求或元数据出现视为公开下载成功。

## 采用的实现与已知限制

人设版本采用 `persona-input-20261108/canonical-d-source.json` 对应输入逻辑，运行源码在正式版本号调整前已经与已安装本地包逐字节匹配。页面单段 `prompt` 可无损还原字段，原生恢复会话不会额外夹带旧问答；身份、规则、示例和引用资料按各自职责进入实际请求。未采用把角色块后移、删掉例句或去掉具体反例等未稳定改善的实验。

此前当前模型 `haina / deepseek-v4.1-flash` 完成 60 次合成调用，其中 36 次是同问题、同参数输入对照；每臂仍有明确语义失败。原始回答与失败完整保留，详见[同模型验收与纠正](AGENT-MODEL-VALIDATION-2026-11-08.md)。本版修复输入逻辑与程序边界，不宣称任意模型都能完整执行角色、数量、时间和事实要求。本机模型和参数不因发布而改变。

知识库页面、导入与检索接口及其 PDF 依赖已移除，已有资料文件不自动删除。会话与长期记忆、图片、提醒、素材和联网搜索保留。
