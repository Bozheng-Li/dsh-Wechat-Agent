# 人设提示重写 · 2026-11-07

本轮重写当前会话人设的应用规则、默认全局身份、自然表达习惯、主动参与判断和 18 套内置模板。改动属于未发布的本地更新，版本仍为 `0.2.0-preview.6`。用户已保存的人设、账号与授权配置保留；使用新版内置模板需要重新载入、核对草稿并保存。

## 问题与改动

旧提示把较长的通用表达、身份说明、角色规则和最终核对反复叠加。默认身份中禁止编造家人、关系的笼统表述容易与管理员保存的角色背景冲突；通用格式规则还压制古风、角色动作等明确的人设特点。修复后的通用规则只补足未配置的部分，配置名字是角色自称的来源，词汇、句式、态度和情绪反应落实在正文，认真回答也保留角色的表达方式。

管理员全局身份与账号要求共同生效，同一呈现事项冲突时全局明确要求优先。管理员保存的背景、关系及回答约定优先于默认设定和历史旧说法。固定开头、结尾、语言、署名及指定的独立首末行保留。正常角色互动可直接使用设定；追问现实真实性时区分设定与现实，直接问是否 AI 时如实回答。

| 来源 | 当前职责 |
| --- | --- |
| `src/features/agent/prompts.mjs` | 统一构建普通聊天、昵称唤醒、主动参与、知识回答、到期任务及图片配文的系统规则；条件工具只描述实际开放的能力 |
| `src/features/agent/runner.mjs` | 保留执行前的模型、人设和配置快照、微信身份及记忆 JSON 引用、宿主工具隔离与真实完成结果 |
| `src/features/agent/identity.mjs` | 新默认身份；仅识别并升级精确旧默认，用户自定义 Markdown 保留 |
| `src/features/agent/reply-style.mjs` | 简短的默认表达习惯；风格问题仅本地标记，不二次调用、不截断或拦截已完成正文 |
| `src/shared/persona-presets.mjs` | 18 套新背景、互动习惯、口吻与示例，保留原有 ID、名字、别名、分类和编辑接口 |
| `src/features/conversation/natural-chat.mjs` | 参与倾向只影响开口意愿；时间与条数由后台处理，最终 JSON 协议只进入实际陪聊判断 |

自然陪聊的 JSON 协议最后追加，固定文字只写入 `reply.text`，`skip.text` 为空。知识回答的原文与引用约定也最后追加。图片配文是实际发送正文，使用同一会话人设与固定要求；空配文仍只发图片。按需图片理解、表情包跳过、完整长回复及真实回执边界保留。

记忆整理、长期提取、图片理解和工作台内部任务按后台模式隔离，即使没有 `systemOverride` 也不继承聊天人设、固定署名或工具。旧实现只有同时提供专用提示时才隔离，已补上无专用提示的回归。

旧默认身份按规范化换行后的 SHA-256 识别。本次改写前的 819 字符默认前缀后追加自定义内容时，仅在构建提示时替换已识别的默认部分，保留追加约定；不会改写用户文件。修改过前缀的 Markdown 不作替换，UTF-8 BOM 和 Windows 换行有覆盖验证。
