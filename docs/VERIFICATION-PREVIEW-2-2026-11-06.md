## 定时任务与消息可靠性

| 触发条件 | 行为与验证 |
| --- | --- |
| “小胖，一分钟后提醒我吃饭” | 保存任务后简短确认，真实时钟到期后提醒，回执后标记完成，继续等待没有重复执行 |
| 定时 Agent 需要饮食偏好及配图 | 读取该会话的持久事实和窗口记忆；只能选择启用素材；配文与图片完整确认后完成 |
| 生成中取消或撤销授权 | 停止发送，保留原记忆及重要来源；重新授权不自动补发 |
| 图片转换过程中取消或撤权 | 转换完成后再次核对取消状态与授权，不越过发送边界 |
| 排队超过有效时间、离线或未授权 | 不发送过期提醒；等待或记录跳过原因 |
| 缺少有效回执、部分确认、结果不明 | 暂停任务，保留真实结果，重启后不自动重发 |
| 取消后收到真实确认 | 保留已确认发送结果，不重排任务，不改写为“未发送” |
| 父进程账号状态稍滞后 | 独立 worker 核对当前登录账号；错误账号、缺账号和未登录均在调用协议发送前拒绝 |

单独的一分钟测试命令：`node scripts/test-scheduler-clock.mjs`。它使用真实调度循环与持久化，传输和回执为隔离替身，实际微信消息数为 0。

## 记忆与视觉

会话窗口每轮注入，压缩前归档原文，图片理解写入同一来源；压缩和编辑并发时保留新消息。长期 Markdown 是独立权威内容，已删除、清空或手动修订的来源不会被异步提取覆盖或重新填回。自动事实保留会话来源，其他群和私聊不会看到；手工全局备注按账号共享。

真实模型验证发现当前聊天型号在 DSH 中只声明文字输入，因此图像自动路由到同一服务中明确支持视觉的同系列模型。图像描述再提供给聊天模型，未修改用户已保存的模型选择。全部真实模型验证使用虚构人物与合成图片。

## 适用范围

图片上传协议通过公开字段布局互证及隔离分片/回执测试，本轮没有向真实微信会话发送测试图片，不能把隔离回执当作真实微信服务器联调结果。GIF、WebP 保留原件，发送首帧静态 PNG；当前不发送原生动态表情。自然聊天已增加全局规则与一次改写，但模型输出仍有变化，不能保证所有回复都符合每个人的口语偏好。

维护群通知保持关闭。私有测试报告、截图和运行数据位于 `storage/logs/`，不进入源码提交或 npm 包。
