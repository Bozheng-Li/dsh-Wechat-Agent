# 本机预览更新 · 2026-11-06

本机 DSH 的微信 Agent 已通过原生插件 CLI 安装本次未发布整合构建。基础版本号仍为 `0.2.0-preview.2`，文件内容与 npm 已发布的同名版本不同；本次未发布 npm 或更新公共市场索引。

## 用户可见变化

- “素材 → 内置表情包”提供猫咪心情 9 张、软萌动物 10 张、元气心情 11 张。三组首次默认关闭，可分别启用；预览不要求先启用。
- 定时任务使用“当前任务 / 历史记录”布局，已结束任务每项一行，可展开执行详情与回执。
- 本次一并安装当前已通过整合验收的全局身份、会话人设、按需记忆、全局工作目录和群聊提醒 @ 功能；原设置未被更改。

刷新 DSH 页面后进入微信 Agent。若仍显示原页面，重新加载 DSH 窗口，使前端载入已更新的插件文件。
