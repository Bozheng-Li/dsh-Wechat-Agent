# App 业务能力同步（未发布）

本轮把独立 App 的适用业务改进移植到插件。插件继续使用 DSH 的模型、凭据、原生会话和工作能力；没有引入独立 App 的 HTTP 模型执行器、Electron 外壳或安装更新器。

## 使用变化

- 设置 → 自动功能：自动回复、定时任务和朋友圈三个独立开关。旧配置缺少后两个开关时继续跟随原来的自动回复状态；第一次修改时保存各自状态。
- 设置 → 默认助手：当前人设、人设库、试聊。最多保留 12 个人设，所有会话使用当前选中的一条。可以读取当前授权聊天、提炼可编辑的语言档案，再保存使用。
- 高精度人设为可选项，默认标准模式。高精度先整理事实、完成工具，再通过独立且没有工具的 DSH 会话表达，沿用本轮固定的模型选择与时间语境。需要回复时增加模型调用。
- 群聊参与统一选择按新消息、冷场开口、连续接话。新建只开启消息机会；旧条数模式不会因升级获得冷场权限。直接呼叫仍优先处理。
- 私聊和普通群的人工账号回复也能进入对应授权会话的历史；模型输入明确作者、方向、顺序和时间。旧摘要带来源标记，相关近期更正在它后面呈现。
- 人物检索处理代词边界、话题切换和省略追问。人物卡保存变更时的证据快照；背景整理较晚不再无声抹掉已有资料，时间边界不确定时明确说明。明确删除和撤权仍阻止历史回读。
- 表情按当前语境从完整启用库提供少量预读候选，自然参与也可使用；仍需满足间隔、含义、授权和每轮限制，选择素材不等于已经发送。
- 正文使用 `<SPLIT>` 指定业务分条，代码围栏内的标记保持字面内容。底层微信长文本仍可能按协议字节上限拆分，一次业务发送可能返回多个回执。
- 正文未收到时，开启回复的授权私聊及原生 @ 当前账号的群消息会收到固定提示，模型不猜测引用内容。其他不可读群消息只记录，不凭昵称或参与设置猜唤醒。
- 聊天生图使用已配置的生图接口，不要求素材库预先存在图片。新图独立归档实际提示词、模型和原图；确认发送后再记录送达关联，供后续按图追问。

## 持久化和后台执行

- 消息发送前保存分段计划；每段记录已确认、结果不明或未发送。恢复只处理能明确确认未发送的部分，不重放已确认或结果不明的部分。
- 暂停某项自动功能只取消它自己的执行。管理员已设置的朋友圈自动互动也按朋友圈开关复核，不因聊天开关关闭而卡在最终赞评提交。
- 临时写入失败、残留临时文件和锁释放失败有独立恢复；外部修改配置不再连带阻止无配置变更的消息状态保存。启动清理只按真实授权对象和持久化业务范围发现撤权，不把远程管理员名单扩成空私聊撤权；撤权也不会等待忽略 AbortSignal 的发送通道无限结束，普通取消仍保留真实 ACK。
- 会话与长期记忆减少重复全量解析，状态保存使用脏标记。缓存保留独立快照，外部文件变化会使缓存失效。
- 调度器单次异常重试，连续五次失败才停止；周期从原计划锚点推进。保留插件已有的一次提醒迟到期限、有界重试与未知结果暂停保护。
- 朋友圈补充发布恢复落盘、并发设置版本核对、有限评论分页、屏蔽标签不完整时保留已知成员等修复。
- 执行轨迹支持按日期清理、坏索引容错和可配置保留期。已有数据默认长期保存；仅在用户选择保存期限后进行后续清扫。设置写入带实例归属的 `storage/traces/settings.json`，不往共享 YAML 添加 App 不认识的新字段。

## 两端数据边界

插件可以读取 App 的人设库、独立自动开关、群参与和 DeepSeek 搜索字段。插件保留 DSH 原生搜索值，并使用 DSH 凭据服务，配置别名不会复制密钥。

当前 App 不管理插件的工作会话字段；使用 App 保存共享目录配置时，可能省略这些字段。切回插件需要核对工作会话设置。两端不能同时写入同一数据目录，原有实例锁继续生效。

人设提炼做基础脱敏后再提交给配置的模型；采样片段仍可能含私人信息。长期记忆中的逐字证据继续保留原话，不能把提示词中的脱敏要求当作所有落盘资料都已脱敏。

## 验证记录

本轮使用隔离临时存储、合成模型与微信回执验证；不向真实会话发送测试消息，也不修改 App 工作区。构建、回归和原生 DSH 接入结果在根目录更新日志记录。源码同步、构建产物和运行实例更新分别核对，未发布源码不会自动替换已安装插件。
