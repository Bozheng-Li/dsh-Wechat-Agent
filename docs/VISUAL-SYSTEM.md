# 微信 Agent 视觉系统

界面面向日常管理微信助手的用户。优先让人找到内容、理解状态并完成操作。中性表面承载内容；颜色只承担少量操作强调和明确的状态语义。

## 样式归属

`frontend/styles/base.mjs` 只组合模块，不定义覆盖规则。每类组件只有一处主要样式来源。

| 文件 | 负责范围 |
| --- | --- |
| `tokens.mjs` | 明暗颜色、字体、圆角与动效变量 |
| `foundation.mjs` | 按钮、输入、表单操作、标题、标签、反馈、空态、筛选与页签 |
| `layout.mjs` | 侧栏、窄窗口导航、工作区、概览与账号连接 |
| `automation.mjs` | 工作、提醒、简报、朋友圈，以及共享工作区布局 |
| `content.mjs` | 处理记录、记忆文档、图片记忆、素材图库与编辑弹窗 |
| `settings.mjs` | 设置、会话、管理员和群选择器、运行检查、发送恢复 |

旧的 optical、studio、modules、picker 和 workbench 主题文件已移除。不要追加新的整站覆盖层；修改组件所属文件。模块专用类应体现业务范围，例如 `wa-image-generation-settings` 与图片记忆设置分别命名，避免相互污染。

## 组件规则

- 普通 section 使用间距与细分隔线。编辑器、选中项目和弹窗按用途设置表面，不给每个字段和列表项添加浮动卡片。
- 人物角色卡以一个人物为一张独立卡片，使用稳定的柔和封面色和姓名头像；卡片摘要展示已有资料，完整资料和纠正在卡片详情中完成，资料字段保持清楚的分隔。
- 按钮默认 34px 高，窄屏 36px；主操作使用实心墨色，次操作描边或透明，危险操作有明确文字。悬停、按下、禁用、处理中与键盘焦点分别定义。
- 输入控件圆角 6px，有明确标签、说明和焦点；保存条提示未保存状态并保留取消。说明通过 `aria-describedby` 关联到控件。
- 页签表示页面内分区，分段筛选表示列表条件，二者使用不同外观。页签支持左右方向键、Home 和 End。
- 桌面侧栏保留图标和文字。800px 以下使用可展开页面目录，选中后关闭；Escape 关闭并将焦点返回开关，点击外部关闭。
- 文档保留足够行距，元信息与正文分层。长路径可以换行；表格在窄窗口重排或在明确区域横向滚动。
- 素材与图片弹窗限制在视口内，支持键盘焦点循环与返回；事实删除使用取消优先的独立确认框。
- 空态说明当前情况并提供适当入口；错误和结果不明保留真实文字，不用成功颜色掩盖。任务执行与微信送达分别呈现。
- 系统减少动态效果与已有关闭动效偏好均生效。

## 验证

使用隔离合成账号和本地 RPC fixture 检查页面，不操作真实微信资料。视觉检查覆盖页面和深层状态、明暗主题、桌面和窄窗口、长页滚动、表单名称、页签关联、焦点、文字对比度与布局溢出。图片和复杂背景仍需人工看图，自动通过不能代替美术判断。
