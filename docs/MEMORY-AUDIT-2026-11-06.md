# 记忆功能验收 · 2026-11-06

本轮核对局部窗口、长期 Markdown、按需查询及消息队列中的实际读写结果。测试使用隔离账号、会话、文件目录和发送回执。源码修复已纳入 `0.2.0-preview.6`；真实 DSH 模型的语义验收与运行插件的安装结果单独记录。

## 本轮发现与修复

| 触发条件 | 修复 | 结果证据 |
| --- | --- | --- |
| 模型将一个长期事实标为更正，同时返回与旧事实相同的正文 | 先确定哪些旧事实会失效，再对仍然有效的正文去重，确保替换后的事实继续可用 | 修复前有效事实从 1 条变成 0 条；修复后重新实例化记忆库仍能读到该事实 |
| 摘要生成期间，同一消息的图片理解刚刚完成 | 比较被压缩条目的完整内容；内容改变时取消旧摘要落盘，保留新笔记 | 修复前图片说明消失；修复后拒绝覆盖，新实例仍读到“周五十点在书店见面” |
| 图像任务已经取消，底层模型仍返回迟到结果 | 模型返回后、读取并写入记忆前再次检查取消状态 | 取消后记忆文档和版本完全不变 |
| Markdown 或局部 JSON 的 UTF-8 字节损坏，但结构标记仍完整 | 严格解码，禁止把替换字符当作可信资料交给模型；长期 Markdown 修复前归档原始字节 | 两种记忆均报告明确错误；原始文件完整保留，修复归档与原始损坏字节一致 |
| 长期记忆路径被替换为目录、链接或过大文件 | 有大小限制的普通文件读取；错误页不绕过检查再读取；编辑、清空和提取在后端独立拒绝 | 非普通文件只读，提取不调用模型，待处理来源仍保留 |
| 归档目录被改为重定向目录 | 编辑和清空前核对归档目录，先成功归档再更新删除标记 | 修复前内容写入重定向目录；修复后正文和重定向目标都不变 |
| 关键词位于超长一行的第 24000 字之后 | 返回围绕命中位置的原文摘录，保留大小写与字符形式，并明确标记截断 | 修复前返回 `found: true` 却丢掉命中内容；修复后包含完整约定且输出不超过 24000 字 |
| 真实模型一次使用“阿禾 见面 约定 偏好”等多个关键词 | 按空白和常用分隔符拆词，任一词命中即可返回，按命中数量排序；同一长行的远距离命中均保留上下文 | 修复前把整串词作为连续短语而返回无记录；修复后多词检索和远距离摘录回归通过 |
| 查询用“偏好”，实际事实写成“喜欢猫”；词面筛选被模型误认成完整资料 | 不超过 6000 字的当前范围资料完整返回；`found` 表示有资料，`queryMatched` 表示词面命中；长资料明确 `coverage`、`omitted` 和继续读取提示 | 真实模型复测 C 重现“有猫偏好却说未记录”，补充短文语义差异、全词未命中、长文省略三项断言，修复前均失败 |

本轮新增 14 项回归，覆盖上述缺陷及更正去重、不可读取正文的后端保护、远距离多词摘录和检索结果完整性。真实模型发现的两个检索问题均使用实际生成的查询复现，再修改实现。

## 真实模型语义验收

存储和流程回归不能单独证明模型能正确理解事实。另行通过当前微信插件选择的 DSH 模型（未指定时使用 DSH 默认选择）运行合成 A/B 会话：自动提取、局部清空、实例重建、分别召回、另一账号同会话 ID、明确纠正、实际 `wechat_memory` 调用、删除与清空后不猜测；同时检查强押韵和固定签名身份不污染内部 JSON。

实测入口为本机 `storage/tmp/run-core-model-audit.cjs`。每次执行冻结源码和构建产物，保存 SHA-256；只读核对运行账号、配置、凭据状态和连接健康，所有回复进入合成传输回执。

复测 B 和 C 的前五段均通过，第六段分别暴露上述多关键词和资料完整性问题。修复后复测 D 的 **8 / 8 段全部通过**，并逐条审阅了实际模型正文、存储事实和工具结果。
