# 全局视觉优化 · 2026-11-06

本轮在 `0.2.0-preview.4` 之后的源码中完成冷白、石墨主题与记忆页调整。本地构建、38 组完整界面交互和最终主题的 4 组视觉专项均通过。本次更新已随 `0.2.0-preview.6` 发布并完成本机升级，详见[发布与安装记录](LOCAL-RELEASE-PREVIEW-6-2026-11-06.md)。原有未提交修改保留，用户可见变更与应用内更新日志共用根目录 `CHANGELOG.md`。

全局采用冷白与石墨的明暗主题，使用中性色区分背景、导航、内容表面和输入区域，绿色用于微信连接等真实状态。重新调整标题、说明、留白与边框，使会话、记录、记忆、任务、人设和素材共用清晰的视觉层次；明暗模式跟随 DSH。

工作台改为非对称主区：对话入口与独立的微信连接面板并列显示，提供“管理会话”和“查看记录”入口；三项统计合并为一条紧凑数据栏。主视觉使用本地 SVG 绘制金属与玻璃双环，配合小幅、缓慢的悬浮效果。装饰不接收点击，不进入辅助技术的内容，也不表示微信连接或任务运行状态。右上角动效开关保存在本机浏览器，系统减少动态效果设置始终优先。

人设库改为书刊式网格，以分类、名字、角色和大字印组织卡片，标签使用简洁的文字分隔；移除重复的说明底栏与箭头，每张卡片保留一个明确的预览入口。既有分类、搜索、全文预览和载入行为保留。

记忆页加入会话概况、近期消息数、字符数、压缩次数和窗口容量条，窗口设置默认折叠。全局长期记忆将共同备注、来源事实和文件维护分区呈现，窄窗口按阅读顺序排列。两个标签页支持方向键与 Home/End；切换保留未保存草稿，撤销恢复已存内容。保存会话记忆期间暂停切换会话；全局文件无法安全读取时显示原因并关闭写入操作，修复后可重新读取。

## 问题与修复

| 触发条件 | 修复 | 验证结果 |
| --- | --- | --- |
| 首页卡片权重接近，日常入口与连接控制混在一起 | 改为非对称主区、独立连接面板与紧凑统计栏 | 明暗截图审阅完成；完整交互通过 |
| 人设卡片底部重复说明和箭头较多 | 使用书刊式网格与单一预览箭头 | 分类、搜索、预览、载入、撤销及保存失败后重试通过 |
| 较窄窗口中双环主体被右边界过度裁切 | 根据窗口宽度缩放和内收雕塑，保持正文在前景 | 1024、430、360、320 像素截图人工核对，双环主体和操作可见 |
| 统一输入框内边距时覆盖了搜索框原有图标间距 | 搜索框保留独立的左右内边距 | 本轮人设搜索图标间距和会话、记录搜索检查通过 |
| 手动断开连接后，上一轮登录状态仍为 `online` | 离线时不使用旧“微信已连接”提示 | 本轮隔离断开显示“微信离线”；重连恢复真实连接提示 |
| 各群修改了主动参与间隔，工作台仍固定描述为 5–20 条 | 说明改为按各群设置的消息条数参与 | 本轮随机、固定间隔及单会话设置交互通过 |
| 记忆摘要正在保存，用户切换到另一会话 | 保存期间锁定会话选择与筛选，保存完成后恢复 | 实际暂停保存 RPC，确认只写原会话，其他会话保持不变 |
| 全局记忆文件不是可安全读取的普通文件或超过读取上限 | 显示只读原因，阻止编辑、清空和提取，保留重新读取 | 用 8,000,001 字节隔离文件复现；原字节恢复后编辑与备注正常 |
| 测试直接点击隐藏标签页或折叠内容，可能出现误判通过 | 点击、输入和读取辅助函数检查实际可见性；先展开再操作 | 本轮草稿、撤销、键盘焦点、容量和只读检查均通过 |
