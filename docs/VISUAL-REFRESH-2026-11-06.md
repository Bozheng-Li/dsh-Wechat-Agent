# 全局视觉优化 · 2026-11-06

本轮美术更新已随 `0.2.0-preview.4` 正式发布，并通过 DSH 原生命令安装到本机；公开完整包与全部安装文件均已核验。用户可见变更与应用内更新日志共用根目录 `CHANGELOG.md`，详细结果见[正式升级记录](LOCAL-RELEASE-PREVIEW-4-2026-11-06.md)。

统一使用玉色与墨绿的明暗主题，区分页面背景、导航、卡片和输入区域；调整标题、说明、留白、细边框、内侧高光及投影。会话、记录、记忆、任务、人设和素材共用同一套视觉层次，明暗模式跟随 DSH。

工作台新增轻量立体对话气泡，使用本地 CSS 几何与光影，不增加渲染引擎、远程图片或字体依赖。气泡缓慢悬浮，人设与素材提供轻微悬停反馈；装饰不接收点击，不进入辅助技术的内容，也不表示微信连接或任务运行状态。右上角动效开关保存在本机浏览器，系统减少动态效果设置始终优先。

## 问题与修复

| 触发条件 | 修复 | 验证结果 |
| --- | --- | --- |
| 统一输入框内边距时覆盖了搜索框原有图标间距 | 搜索框保留独立的左右内边距 | 人设搜索文字与图标间距检查通过；会话及记录搜索交互通过 |
| 手动断开连接后，上一轮登录状态仍为 `online` | 离线时不使用旧“微信已连接”提示 | 隔离断开显示“微信离线”，在线指示消失；重连恢复真实连接提示 |
| 各群修改了主动参与间隔，工作台仍固定描述为 5–20 条 | 说明改为按各群设置的消息条数参与 | 既有随机、固定间隔及单会话设置交互通过 |
