## 用户操作

进入“素材 → 内置表情包”，使用各组开关。首次默认关闭，启用时从插件包内加入当前账号的素材库，无需联网下载或先调用视觉模型。整组停用保留图片、编辑内容和单张开关；重新启用可补回从素材库删除的内置图片。其他账号的设置独立保存。

ZIP 按包名形成分组，同名 ZIP 再次导入沿用已有开关；单图与旧版未分组素材归入“我导入的图片”。这些组也有整体开关，素材列表支持按组筛选。图片回复总开关、概率、间隔和会话授权继续参与发送判断。

针对分组状态检查了以下触发条件及结果：

- 已选中素材后停用分组：在素材准备前和准备后、真正调用发送前都能阻止图片发出。
- 微信发送已在途时停用分组：等待取消与最终回执核对，再保存停用；迟到的真实成功回执仍保留，不能假报未发送或再次重发。
- 分组保存失败：原状态与已有素材不变；新加入的图片回滚；界面显示错误，开关不假报成功。
- 图包缺图或内容损坏：在导入任何该组图片之前失败，不留下半组素材。
- 重新启用：不覆盖既有名称、含义、类型和单张停用设置；相同图片继续保留原来的归类。
- 重启和账号切换：分组状态持续保存，其他账号默认关闭；旧版素材与图片回复设置保持兼容。
- ZIP 分组关闭后再次导入同名包：新图片仍受已关闭的分组约束。
- 调用分组管理或预览接口：非本机所有者、过时账号请求均被拒绝；模型只有素材搜索与选择能力，不能启用分组。
