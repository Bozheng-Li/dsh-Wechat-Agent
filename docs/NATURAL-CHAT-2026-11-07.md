# 自然陪聊本地试用记录

2026-11-07，北京时间。此次功能为未发布的本地试用，安装包位于 `release/unreleased-natural-chat/`，基础版本号仍为 `0.2.0-preview.6`，未发布 npm 或推送 Git。

在微信 Agent 的“会话 → 授权群的设置 → 回复模式”选择第四档“自然陪聊”，保存后只对该群生效。原有 @、`/agent`、昵称唤醒及固定／随机 1–100 条设置继续使用。时间与条数提供参与机会，模型结合本群话题一次判断发言或保持安静。

| 设置 | 默认值 |
| --- | --- |
| 参与性格 | 自然，可选安静或活跃 |
| 时间间隔 | 随机 30–60 分钟，可改固定分钟数 |
| 活跃时段 | 北京时间 09:00–23:00 |
| 智能跳过 | 开启 |
| 连续接话窗口 | 120 秒，最多判断 3 条相关后续 |
| 无人回应退让 | 连续 2 次已确认主动发言无人接话后暂停 |
| 主动最短间隔 | 3 分钟，时间与数量共用 |

直接呼叫优先于未发送的主动任务。生成主动发言期间收到新群消息时，旧内容让位；人工接话会暂缓自动参与。只按真实微信回执累计发言，发送结果不明或部分已确认时暂停自动参与，重启和重连不补发错过的机会。

自动判断只使用当前群的人设、记录与可用记忆，不自动执行搜索、知识库查询或创建提醒。判断和正文由一次模型请求完成；需要的图片理解与记忆压缩仍按原流程执行。
